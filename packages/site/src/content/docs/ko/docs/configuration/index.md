contextlint의 동작은 리포지터리 최상단의 `contextlint.config.json`으로 제어합니다. 이 카테고리에서는 설정 파일 작성 방법, 검증 대상 지정 방법, 규칙 단위의 세밀한 제어를 설명합니다.

## 이 카테고리의 구성

- [설정 파일](/ko/docs/configuration/config-file/) — `contextlint.config.json`의 구조와 각 필드 개요
- [include 패턴](/ko/docs/configuration/include-patterns/) — 검증 대상 파일 지정과 우선순위
- [규칙 단위 스코프 지정](/ko/docs/configuration/per-file-rule-scoping/) — 특정 파일군에만 규칙을 적용
- [설정 파일 자동 감지](/ko/docs/configuration/auto-detection/) — `findConfig`의 상위 디렉터리 탐색

# Task - 任务详情画面

## 画面概要

| 项目 | 内容 |
|------|------|
| 画面名 | 任务详情 |
| URL | `/tasks/:id` |
| 概要 | 显示和编辑任务的详细信息 |

## 画面项目

| No | 项目名 | 类型 | 稳定度 | 说明 |
|----|--------|------|--------|------|
| 1 | 任务标题 | 文本输入 | stable | 可编辑 |
| 2 | 描述 | 文本域 | review | 支持 Markdown |
| 3 | 状态 | 下拉选择 | review | todo / in_progress / done |
| 4 | 标签 | 多选 | draft | 添加或移除标签 |
| 5 | "删除"按钮 | 按钮 | review | 删除任务 |

|------|------|------|

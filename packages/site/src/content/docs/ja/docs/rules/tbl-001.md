---
title: TBL-001 必須カラム
description: テーブルに必須カラムが存在することを検証する。
---

## 概要

テーブルのヘッダー行に必須カラムがすべて含まれていることを検証します。`requiredColumns` で指定した列名のいずれかが存在しないと **error** になります。

## なぜ必要か

要件テーブル、API スペック、データ定義などで、特定の列（`ID`、`Status`、`Owner` など）が必ず存在することをチームで合意していても、新規テーブルを書く際に列ごと忘れる、テーブル構造を一部だけ書き換えて他を忘れる、といったミスが発生します。このルールがそれを防ぎます。

## オプション

| フィールド | 型 | 必須 | 説明 |
|----------|------|------|------|
| `requiredColumns` | string[] | ✓ | 必須とする列名の配列 |
| `section` | string | — | 検証対象を特定セクション配下のテーブルだけに絞る（見出しに含まれる文字列） |
| `files` | string | — | このルールを適用するファイルの glob |

## 違反例

```markdown
## 要件

| ID     | 内容             |
| ------ | ---------------- |
| REQ-01 | ユーザー登録     |
```

`requiredColumns: ["ID", "Status"]` を設定している場合、`Status` カラムが無いため違反になります。

```text
docs/requirements.md
  line 3  error  Missing required column "Status" in table  TBL-001
```

## 修正後

```markdown
## 要件

| ID     | 内容             | Status |
| ------ | ---------------- | ------ |
| REQ-01 | ユーザー登録     | stable |
```

## 設定例

```json
{
  "rule": "tbl001",
  "options": {
    "requiredColumns": ["ID", "Status"],
    "section": "要件",
    "files": "specs/*.md"
  }
}
```

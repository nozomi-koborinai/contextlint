# Task - 任务列表画面

## 画面概要

| 项目 | 内容 |
|------|------|
| 画面名 | 任务列表 |
| URL | `/tasks` |
| 概要 | 以列表形式展示用户的任务 |

## 画面项目

| No | 项目名 | 类型 | 稳定度 | 说明 |
|----|--------|------|--------|------|
| 1 | 任务标题 | 显示 | stable | tasks.title |
| 2 | 状态标签 | 显示 | review | 按 tasks.status 分色显示 |
| 3 | 创建日期 | 显示 | stable | tasks.created_at |
| 4 | "新建"按钮 | 按钮 | stable | 打开任务创建对话框 |

## 画面跳转

| 来源 | 操作 | 目标 |
|------|------|------|
| 本画面 | 点击任务 | [任务详情](./screen_task_detail.md) |

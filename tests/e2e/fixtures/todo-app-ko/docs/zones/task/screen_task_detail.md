# Task - 태스크 상세 화면

## 화면 개요

| 항목 | 내용 |
|------|------|
| 화면명 | 태스크 상세 |
| URL | `/tasks/:id` |
| 개요 | 태스크의 상세 정보를 표시하고 편집한다 |

## 화면 항목

| No | 항목명 | 종류 | 안정도 | 설명 |
|----|--------|------|--------|------|
| 1 | 태스크 제목 | 텍스트 입력 | stable | 편집 가능 |
| 2 | 설명 | 텍스트 영역 | review | Markdown 지원 |
| 3 | 상태 | 선택 | review | todo / in_progress / done |
| 4 | 태그 | 다중 선택 | draft | 태그 부여 및 해제 |
| 5 | "삭제" 버튼 | 버튼 | review | 태스크를 삭제 |

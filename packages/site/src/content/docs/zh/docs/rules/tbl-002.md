---
title: TBL-002 空单元格
description: 验证表格的单元格非空。
---

## 概述

验证表格的单元格非空。指定 `columns` 时仅检查这些列,未指定时则检查所有列。违例以 **warning** 报告。

## 为什么需要

在需求表中将 `Status` 列留空就提交新行,或在 API 表中忘记填写 `说明`,都会降低文档的完成度。这类问题在评审中不易察觉,机械化检测有其价值。

## 选项

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `columns` | string[] | — | 验证目标的列名。未指定则覆盖所有列 |
| `files` | string | — | 应用此规则的文件 glob |

省略全部选项也可工作(覆盖所有表格 × 所有列)。

## 违例

```markdown
## 需求

| ID     | 内容             | Status |
| ------ | ---------------- | ------ |
| REQ-01 | 用户注册         | stable |
| REQ-02 | 重置密码         |        |
```

设置 `columns: ["Status"]` 或不指定 `columns` 时,会检测到空单元格。

```text
docs/requirements.md
  line 5  warning  Empty cell in column "Status"  TBL-002
```

## 修正后

```markdown
## 需求

| ID     | 内容             | Status |
| ------ | ---------------- | ------ |
| REQ-01 | 用户注册         | stable |
| REQ-02 | 重置密码         | review |
```

## 配置示例

```json
{
  "rule": "tbl002",
  "options": {
    "columns": ["Status", "Owner"]
  }
}
```

# Task - 비즈니스 가치와 요구사항

## 비즈니스 가치 (Why)

사용자가 일상의 태스크를 관리하고 진행 상황을 추적할 수 있도록 한다.

## 요구사항 (What)

### 태스크 관리

| ID | 요구사항 | 안정도 | 근거 |
|----|---------|--------|------|
| REQ-TASK-01 | 태스크를 생성할 수 있을 것 | stable | 기본 기능 |
| REQ-TASK-02 | 태스크 목록을 표시할 수 있을 것 | stable | 기본 기능 |

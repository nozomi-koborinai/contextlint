contextlint 的行为通过仓库根目录下的 `contextlint.config.json` 控制。本类别介绍配置文件的写法、检查目标的指定方式，以及规则级别的精细控制。

## 本类别构成

- [配置文件](/zh/docs/configuration/config-file/) — `contextlint.config.json` 的结构与各字段概览
- [include 模式](/zh/docs/configuration/include-patterns/) — 检查目标文件的指定方式与优先顺序
- [规则级别的范围限定](/zh/docs/configuration/per-file-rule-scoping/) — 仅对特定文件群应用某条规则
- [配置文件的自动检测](/zh/docs/configuration/auto-detection/) — `findConfig` 的父目录遍历

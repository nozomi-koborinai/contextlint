# Task - 태스크 목록 화면

## 화면 개요

| 항목 | 내용 |
|------|------|
| 화면명 | 태스크 목록 |
| URL | `/tasks` |
| 개요 | 사용자의 태스크를 목록으로 표시한다 |

## 화면 항목

| No | 항목명 | 종류 | 안정도 | 설명 |
|----|--------|------|--------|------|
| 1 | 태스크 제목 | 표시 | stable | tasks.title |
| 2 | 상태 뱃지 | 표시 | review | tasks.status를 색상으로 구분하여 표시 |
| 3 | 생성일 | 표시 | stable | tasks.created_at |
| 4 | "새로 만들기" 버튼 | 버튼 | stable | 태스크 생성 모달을 연다 |

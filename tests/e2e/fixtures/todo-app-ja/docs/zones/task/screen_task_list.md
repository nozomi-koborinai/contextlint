# Task - タスク一覧画面

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面名 | タスク一覧 |
| URL | `/tasks` |
| 概要 | ユーザーのタスクを一覧表示する |

## 画面項目一覧

| No | 項目名 | 種別 | 安定度 | 説明 |
|----|--------|------|--------|------|
| 1 | タスクタイトル | 表示 | stable | tasks.title |
| 2 | ステータスバッジ | 表示 | review | tasks.status を色分け表示 |
| 3 | 作成日 | 表示 | stable | tasks.created_at |
| 4 | 「新規作成」ボタン | ボタン | stable | タスク作成モーダルを開く |

## 画面遷移

| 遷移元 | アクション | 遷移先 |
|--------|-----------|--------|
| この画面 | タスクをクリック | [タスク詳細](./screen_task_detail.md) |

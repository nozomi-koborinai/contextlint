# Task - 業務価値と要件

## 業務価値（Why）

ユーザーが日々のタスクを管理し、進捗を追跡できるようにする。

## 要件（What）

### タスク管理

| ID | 要件 | 安定度 | 根拠 |
|----|------|--------|------|
| REQ-TASK-01 | タスクを作成できること | stable | 基本機能 |
| REQ-TASK-02 | タスクの一覧を表示できること | stable | 基本機能 |
| REQ-TASK-03 | タスクのステータスを変更できること | review | 設計検討中 |
| REQ-TASK-04 | タスクにタグを付与できること | draft | 要件未確定 |
| REQ-TASK-05 | タスクを削除できること | review | 基本機能 |

# Task - タスク詳細画面

## 画面概要

| 項目 | 内容 |
|------|------|
| 画面名 | タスク詳細 |
| URL | `/tasks/:id` |
| 概要 | タスクの詳細情報を表示・編集する |

## 画面項目一覧

| No | 項目名 | 種別 | 安定度 | 説明 |
|----|--------|------|--------|------|
| 1 | タスクタイトル | テキスト入力 | stable | 編集可能 |
| 2 | 説明 | テキストエリア | review | Markdown 対応 |
| 3 | ステータス | セレクト | review | todo / in_progress / done |
| 4 | タグ | マルチセレクト | draft | タグの付与・解除 |
| 5 | 「削除」ボタン | ボタン | review | タスクを削除 |

## 画面遷移

| 遷移元 | アクション | 遷移先 |
|--------|-----------|--------|
| この画面 | 戻る | タスク一覧 |

---
title: TBL-005 컬럼 간 제약
description: 한 컬럼의 값이 조건을 만족할 때 다른 컬럼이 지정된 제약을 만족하는지 검증합니다.
---

## 개요

한 컬럼이 `when`의 조건을 만족할 때, 다른 컬럼이 `then`의 제약을 만족하는지를 검증합니다. 조건부 규칙으로, 행마다 평가됩니다. 위반은 **error** 로 보고됩니다.

## 왜 필요한가

「`Status`가 `stable`일 때는 `Approver` 컬럼이 비어 있지 않을 것」「`Type`이 `external`일 때는 `URL` 컬럼이 `https://`로 시작할 것」 같은 **행 내의 조건부 정합성** 은 허용 값이나 정규표현식만으로는 표현할 수 없습니다. 이 규칙은 그러한 컬럼 간의 관계를 표현합니다.

## 옵션

| 필드 | 타입 | 필수 | 설명 |
|----------|------|------|------|
| `when` | object | ✓ | 조건(아래 참조) |
| `then` | object | ✓ | 제약(아래 참조) |
| `section` | string | — | 검증 대상을 특정 섹션 하위의 테이블로 한정 |
| `files` | string | — | 이 규칙을 적용할 파일의 glob |

### `when`(조건)

| 필드 | 타입 | 설명 |
|----------|------|------|
| `column` | string | 조건을 판정할 컬럼 |
| `equals` | string | 값이 이 문자열과 일치할 때 |
| `oneOf` | string[] | 값이 이 배열의 어느 하나에 포함될 때 |
| `matches` | string | 값이 정규표현식과 일치할 때 |

`equals` / `oneOf` / `matches`는 그 중 하나만 지정합니다.

### `then`(제약)

| 필드 | 타입 | 설명 |
|----------|------|------|
| `column` | string | 제약을 가할 컬럼 |
| `notEmpty` | boolean | 값이 비어 있지 않을 것 |
| `equals` | string | 값이 일치할 것 |
| `oneOf` | string[] | 값이 포함될 것 |
| `matches` | string | 값이 일치할 것 |

`notEmpty` / `equals` / `oneOf` / `matches`는 그 중 하나만.

## 위반 예시

```markdown
| ID     | Status | Approver |
| ------ | ------ | -------- |
| REQ-01 | stable | alice    |
| REQ-02 | stable |          |
```

`when: { column: "Status", equals: "stable" }`, `then: { column: "Approver", notEmpty: true }`를 설정한 경우, `stable`인데 `Approver`가 빈 행이 위반이 됩니다.

```text
docs/requirements.md
  line 4  error  Row where Status="stable": column "Approver" must not be empty  TBL-005
```

## 수정 후

```markdown
| ID     | Status | Approver |
| ------ | ------ | -------- |
| REQ-01 | stable | alice    |
| REQ-02 | stable | bob      |
```

## 설정 예시

```json
{
  "rule": "tbl005",
  "options": {
    "when": { "column": "Status", "equals": "stable" },
    "then": { "column": "Approver", "notEmpty": true }
  }
}
```

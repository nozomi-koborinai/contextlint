# Auth - 비즈니스 가치와 요구사항

## 비즈니스 가치 (Why)

사용자가 안전하게 로그인하여 자신의 태스크만 관리할 수 있도록 한다.

## 요구사항 (What)

| ID | 요구사항 | 안정도 | 근거 |
|----|---------|--------|------|
| REQ-AUTH-01 | 이메일 주소로 로그인할 수 있을 것 | stable | 기본 기능 |
| REQ-AUTH-02 | 비밀번호를 해시화하여 저장할 것 | stable | 보안 요구사항 |
| REQ-AUTH-03 | 로그아웃할 수 있을 것 | stable | 기본 기능 |
